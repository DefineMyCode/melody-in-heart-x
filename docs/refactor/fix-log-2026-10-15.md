## M-3 内嵌歌词（ID3 USLT/SYLT）解析缺陷 ✅ 已修复（重写）

**核实（测试复现，9/14 RED）**：新增 [EmbeddedLyricsParserTest](../../data/src/test/java/cn/com/dcsgo/mihx/data/util/EmbeddedLyricsParserTest.kt)，
用真实字节流逐条证实：
- ISO-8859-1/UTF-8 的空描述符（单 0x00 终止）只解出**最后 1 个字节**（`Hello LRC` → `C`）；
- 编码 3（UTF-8）按 ISO-8859-1 解码 → 中文乱码；
- UTF-16LE 的 BOM 判定读了语言字段字节（`buffer[offset+3]`）→ 字节序判错；
- ID3v2.4 syncsafe 帧长按普通大端读 → 帧行走飞，USLT 丢失；
- 只读前 128KB → 200KB 封面后的 USLT 丢失；
- `InputStream.read/skip` 未循环读满 → 真实流（部分读/部分跳）下 FLAC 歌词块丢失；
- SYLT 未跳描述符（3 字符描述符时必然错位）。

**修复**：`EmbeddedLyricsParser` 重写为逐帧流式解析：
- `readFully` / `skipFully`（skip 返回 0 时退化为 read 吞字节）；
- 描述符终止符按编码区分（0/3 单 0x00；1/2 成对 0x00 且 2 字节对齐），UTF-16 文本按真实 BOM 判定字节序；
- 编码 3 按 UTF-8；v2.4 帧长按 syncsafe；v2.2 帧数据长度修正（原公式多算 4 字节）并映射 ULT/SLT/TT2/TP1；
- 跳过扩展头（v2.3/v2.4 语义分别处理）；16MB 帧数据上限防损坏 tag 大分配；
- FLAC 路径同样 readFully/skipFully，Vorbis Comment 增加长度越界防护。

**结果**：14/14 GREEN。
