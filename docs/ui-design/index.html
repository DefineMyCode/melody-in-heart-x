心有乐章，黑夜也发光Melody in Heart

为「心有乐章」重新设计的界面规范：一套墨色（黑白灰）明暗双主题，深色模式做到 OLED 纯黑熄灭与近白可读； 再新增一套朱砂 · 心有乐章主题，从心跳中提炼的一抹朱砂红——低调沉稳、清爽克制，昼夜皆宜。

本地 · 无广告 · 离线优先 4 套主题 · 支持跟随系统 朱砂红 · 单色强调
01 / OLED

纯黑即熄灭

深色模式背景使用 #000000。在 OLED 屏幕上，这些像素完全不发光——省电、无光晕、更沉浸。

--bg0 → #000000
02 / 克制

近白的暗

深色模式不再使用刺眼的纯白文字，而是「尽可能暗但仍与灰色可区分」的 #D0D0D0，长时间听歌更舒适。

--text1 → #D0D0D0 · --text2 → #9A9A9A
03 / 乐章

朱砂 · 沉稳

从心跳中提炼的一抹朱砂红。深色模式压低亮度、去掉琥珀金，清爽克制——只做点缀，不做主色。

昼 #A32E25 · 夜 #C04F42

为什么是 #000000？

  • OLED 屏幕黑色像素完全熄灭，零发光、零漏光
  • 对比度趋近无穷，封面色块更「深」更沉浸
  • 长期使用更省电，降低烧屏风险
  • 本主题：bg0 与 bg1 均为纯黑，靠轻微灰层表达层级

常见误区：深灰 ≠ 纯黑

  • #121212 在 OLED 上像素仍然发光，只是亮度低
  • 黑色看起来「发灰」，也产生边缘光晕
  • 本设计仅在需要层级时使用 0A–25 的极低灰阶
  • 文字层级靠「近白的暗」而非纯白，减少刺眼

05

设计原则

让主题既可落地到 Material3，也忠实于「心有乐章」的品牌气质。

朱砂不超过 10%

朱砂红只用于「正在发生的动作」：播放键、当前歌词、进度、高亮。大面积留黑白灰，红色才保有「心跳」的分量。

层级靠灰，不靠亮度

深色模式背景纯黑，浮层用 0A→25 的极低灰阶表达「抬升」。文字从 #D0D0D0 到 #9A9A9A 到 #6B6B6B 三级递进。

昼夜两套色温

朱砂 · 昼用沉稳红 #A32E25 压住白底；朱砂 · 夜用压暗的暖红 #C04F42 点亮纯黑，不刺眼。同一情感，两种温度。

信息克制，留白呼吸

一屏只突出一个焦点：封面或当前歌词。列表密度适中，封面、迷你播放栏始终触手可及。

品牌叙事 · 心有乐章

心有乐章

Melody in Heart

心是跳动的朱砂红，乐章是一道沉稳的光。纯黑是夜的底色，近白的暗是留给耳朵的温柔—— 一首歌，从心脏出发，在屏幕上留下一抹会呼吸的红。

主题色命名：朱砂 · 心有乐章（白天 #A32E25 / 夜晚 #C04F42）。单色强调、去琥珀金，深色模式压暗以护眼，贯穿均衡器与播放条渐变。
