FEATURE · MOOD TIME SLOT · v1

情境化随心播放，时段懂你Mood Time Slot Playback

在「我的」页新增随心播放增强：用户按时段配置情绪词条，随心播放与无限随机在命中时段内 只从带有这些词条的歌曲中随机，与全局均匀随机（低播放优先）完全兼容。时段采用左闭右开区间、 支持跨午夜、两两不重叠；每个词条实时展示关联歌曲数，配置即可预见随机池规模。

左闭右开 · 跨午夜 词条过滤 · 计数可见 均匀随机兼容 默认关闭 · 行为不变
01 / 入口

我的页 · 第 5 张卡

入口卡实时反映状态：生效中的时段与剩余时间一目了然；全局开关默认关闭，关闭时随心播放行为与现状完全一致。

数据源 · PlayerSettingsRepository.moodTimeSlotEnabled
02 / 配置

时段 × 情绪词条

时段名 + 时间段（左闭右开，结束早于开始即跨午夜）+ 多选情绪词条。词条按自动分析 / 仅手动标记分组，带歌曲数角标。

存储 · DataStore JSON（time_slot_configs）
03 / 生效

互斥与归因

同一时刻至多一个时段生效；随心播放启动时 toast 明确归因「已按『深夜静谧』为你随机播放」，杜绝"这首为什么被选中"的困惑。

判定 · MoodSlotResolver（域层纯函数）
04 / 兜底

小候选池策略

词条组合下歌曲为 0 → 回退全库随机并提示；<10 首提示"将循环播放"；配置页词条角标让用户在保存前就看到随机池规模。

阈值 · MoodSlotPolicy.POOL_WARN_THRESHOLD

SECTION 02

交互与状态规则

与 docs/architecture/MOOD_TIME_SLOT_PLAYBACK.md 的生效规则一一对应，实现时以此为准。
规则 01 / 互斥

同时至多一个时段生效

区间左闭右开 [start, end)，配置时两两不重叠（编辑页即时校验 + 时间框标红 + 保存禁用）。跨午夜时段在 24h 时间轴上拆两段渲染。

规则 02 / 降级

候选池不足时的三档行为

词条组合 0 首 → 回退全库随机 + toast；<10 首 → 正常生效 + "将循环播放"预警；正常 → 启动 toast 归因一次。列表卡与编辑页合计条均展示可随机数。

规则 03 / 开关

全局一个开关，默认关闭

时段互斥已保证同时至多一个生效，开关只回答"这套自动化整体开不开"。空配置时开关可开但无效果（说明文案如实告知），现有随机行为不受任何影响。

规则 04 / 兼容

与全局均匀随机叠加

增强仅替换随机候选池，分层抢占（低播放优先）与最近播放淘汰照常工作。归因横幅让"这首歌为什么被选中"始终可解释。
