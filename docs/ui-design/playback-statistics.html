02

设计说明 · 交互与数据

四个模块的进入路径、数据口径与空态约定，便于后续落地到 Compose 与存储层。

A今日听歌时长

「播放统计」页首屏，实时反映今天累计的有效播放时长。

  • 大数字：小时 + 分钟，环形进度指向今日目标（可设置，默认 2 小时）。
  • 双增量卡：较昨日、较上周同一天的差值，上升为强调色，下降为中性灰。
  • 底部 24 格迷你条：按小时可视化今日分布，当前小时渐变高亮。
  • 空态：今日尚未播放时显示「今天还没有听歌，去听听吧」。

B本周听歌时长柱状图

自然周聚合（周一 00:00 ~ 周日 23:59），每根柱代表一天的听歌时长。

  • 柱高 = 当天时长占本周单日最大值的比例，柱顶标注分钟数。
  • 今天所在柱子用主题渐变强调，日期标签与其余日期一致（如「二」）。
  • 顶部展示本周合计与较上周百分比增量；无数据日期留空不画柱。
  • 超出一天容量的长音频：按天边界切分，跨天只计入当天播放的时长。

C本周 / 本月歌曲 TOP 榜

按播放次数（rawPlayCount）排序的歌曲热度榜，支持周 / 月维度一键切换。

  • 榜一 / 二 / 三使用奖牌式徽标（强调色、次级色、浅色）；其余为灰色序号。
  • 行尾展示播放次数与正在播放的均衡器动效；点击条目直接播放该歌曲。
  • 预览卡在统计总览展示前三名，入口「查看全部」进入完整榜单页。
  • 完整榜单支持滚动加载，空态展示「本周 / 本月还没有播放记录」。

D入口与统计口径

「我的」页的播放统计卡片升级为单一入口（今日时长迷你预览 + 目标环），点击进入统计总览；原有的「播放次数 / 有效播放次数」两个全量列表收纳到总览页底部「全部歌曲统计」分区，复用现有 PlayStatsScreen，代码不动仅迁移入口。

  • 时长：以 PlayDurationTracker 累计的播放时长为准，暂停 / 拖拽不计入。
  • 周：ISO 自然周（周一起始）；月：自然月，均按本地时区。
  • 榜单：播放次数优先，并列时按最近播放时间升序稳定排序。
  • 增量计算需保留前一日 / 前一周同期的历史快照。
  • 原「播放次数 / 有效播放次数」列表页保持原样，仅把入口迁入统计中心。
