四条核心决策

层级靠光不靠线。整个方向没有一条 1px 边框——卡片浮起靠两层暖色阴影，选中态靠焦糖光晕。这是与现有 UI「outline 分层」最根本的决裂。

Dock 是浮的。底部导航从贴边栏变成悬浮玻璃胶囊，与迷你播放条叠成两层浮岛。.home indicator 区域留空，拇指够得到、视觉轻。

波形是呼吸不是频谱。播放页的柔曲线 3.6 秒一循环，像呼吸而不是仪表。温暖方向拒绝一切「设备感」。

焦糖只做「现在时」。播放键、当前曲、进行中的事是焦糖色；其余一切安静。深色下焦糖换成带光的琥珀。
