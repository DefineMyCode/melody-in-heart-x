四条核心决策

零容器。没有卡片、没有边框盒、没有阴影。歌单列表是报纸排法：一条 1px 细线加 30px 空隙，信息靠字号与字重站住。删掉的是容器，留下的是内容。

陶土色只标「正在发生」。正在播放的歌名、今天的柱子、第一名、进行中的功能——只有「当下」配得上颜色，其余一切都是灰阶。克制是昂贵感的来源。

数字是一等公民。所有时长、次数、规格用 tabular 等宽数字，统计页直接把 72px 的大数字当版面主角——播放器的数据值得报纸头版的待遇。

导航是文字不是容器。底部没有玻璃 Dock 也没有贴边栏，只有三个词和一条陶土短线。安静到几乎不存在，但层级清楚。
