三条观测纪律

星等就是播放次数。越多重听，星等数字越小、星点越亮。播放统计不设专门页——它直接长在每颗星的亮度上，统计中心只是把最亮的排成一列。

白昼不是深色的反色，是另一张图。浅色取十九世纪铜版星图：羊皮青、铜墨、细刻线。夜空模式的发光在白昼模式里换成烫金与雕版阴影，两套主题各自完整，互不迁就。

导航金只负责「指引」。当前项、续读星、出航钮、进度游标——金色永远指向你该去的地方。星云四色只标记情绪，不作他用。
