ROUND 2 · 无隐喻 · 质感优先

音乐就是音乐。
这次把预算全部花在质感上。

上一轮的教训：刊物、仪器、星图——世界观太重，类比盖过了音乐本身。这一轮推翻重来：所有功能回归本名（曲库、队列、定时关闭、情绪标签），不做任何概念包装。新颖感改从三个正统的视觉维度来：形体、光色、排版。三个方向各占其一，深浅主题齐备。

方向一 · 形体

暖砂圆润 · 柔光 · 陪伴感

把「圆」做到极致：超大连续圆角、全胶囊控件、悬浮玻璃 Dock。层级不再靠描边和灰阶，靠多层暖光阴影——像傍晚阳光落在原木家具上。奶油与焦糖配色，一切都是软的。

浅色 · 奶油 / 焦糖深色 · 暖炭 / 琥珀

 方向二 · 光色

流光颜色跟着歌走

整个界面的颜色由正在播放的那首歌决定：从封面取色，晕开成环境光，控制层是磨砂玻璃。换一首歌，整个 App 换一种光。情绪标签直接映射光色——治愈是暖橙的光，静谧是青色的光。原型里可以点「换一首」实时体验。

浅色 · 晨光透雾深色 · 琥珀 / 青蓝 双光演示
打开原型 →
 方向三 · 排版

留白大字 · 大间距 · 高级感

不用卡片、不用边框、不用阴影，层级全部交给字号、字重和留白。48px 的页面标题、76px 的行距、一个陶土色只标「正在发生」的事。安静、昂贵、克制——音乐 App 界里的 Arc 与 Linear。
