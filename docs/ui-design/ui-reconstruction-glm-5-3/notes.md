# 重构手记 · 第二轮

## 〇、第一轮复盘（为什么推翻）

第一轮三案（墨频杂志 / 示波仪器 / 星图天文，已归档至 `archive-round1/`）被整体否决。用户的原话一针见血：

> 「世界观太重，音乐就是音乐别搞什么类比。」

复盘结论：三个方案都在用「隐喻密度」换「记忆点」——歌单叫专栏、队列叫目录、定时叫停印、播放页叫观星台。隐喻一旦侵入命名，功能就有了一层翻译成本；用户每天要的是「放歌」，不是「进入一个设定」。**概念的新颖是给评审看的，质感的新颖才是给用户用的。**

## 一、第二轮的三条纪律

1. **功能全部本名。** 曲库、播放、我的、歌单、队列、定时关闭、随心播放、情绪分析、文件校验、播放统计——一个别名都不起。原型里连文案都按「搜索歌曲、歌单、歌手」「继续播放」「加入队列」这样直给。
2. **新颖感只从正统维度来。** 形体（圆角/阴影/质感）、光色（取色/玻璃/光晕）、排版（字号/字重/留白）——三个方向各占一个维度做到极致，不靠故事撑辨识度。
3. **深浅是两档完整主题，不是反色。** 每案的深浅各自调过对比与材质，切换语义就是普通的「浅色 / 深色」。

## 二、三个方向

### 01 暖砂 Warm Sand（形体维度）
- **一句话**：把「圆」和「暖光」做到极致的陪伴感 UI。
- **做法**：22–34px 连续大圆角、全胶囊控件、悬浮玻璃 Dock；全案零边框线，层级全靠两层暖光阴影；播放页是 3.6 秒一循环的「呼吸波形」而不是频谱仪表。
- **深浅**：奶油+焦糖 / 暖炭+琥珀。
- **强项**：情绪上最「暖」，长时段使用不累；对现有 Material3 骨架的改造最平滑（圆角与阴影都是令牌级改动）。
- **风险**：大圆角对小封面图（40dp 以下）有裁切损失；「软」的气质与 Hi-Res、多版本这些「硬核数据」的展示要靠 mono 数字字重压住。

### 02 流光 Lumen（光色维度）
- **一句话**：整个 App 的颜色由正在播放的那首歌决定。
- **做法**：封面取色 → 主光 g1 / 副光 g2 → 环境光晕染满背景；按钮、进度、情绪标签、封面投影全部继承光色；列表/控制条/Dock 全部磨砂玻璃浮在光上。**情绪分析特色功能第一次可见化**：治愈是暖橙的光、静谧是青光、emo 是紫光。
- **深浅**：同一首歌颜色不变，浅色=晨光透雾、深色=夜里的灯（光晕强度两档）。
- **交互彩蛋**：原型工具栏有「换一首」按钮，三首歌（琥珀/青蓝/紫）实时换整个界面的光色——这是本方向的核心体验，务必点一下。
- **强项**：三案中沉浸感与「活」感最强；且是唯一把「每首歌独一无二」这件事说出来的方案。
- **风险**：取色算法要处理好低饱和封面（fallback 到中性光）；深色下光晕强度需要按内容分级，避免大面积高饱和疲劳。

### 03 留白 Whitespace（排版维度）
- **一句话**：零容器、大字、克制的昂贵感。
- **做法**：没有卡片、没有边框盒、没有阴影；层级全靠字号（48px 标题 / 72px 大数字）、字重、1px 细线加大间距；陶土色是全案唯一彩色，只标「正在发生」的事（正在播放、今天、第一名、进行中）；所有数字 tabular 等宽。
- **深浅**：暖灰纸+陶土 / 暖黑+蜜橘。
- **强项**：三案中最耐看、最不追流行（十年后仍成立）；对信息密度大的列表（本地音乐 400+ 首）最友好。
- **风险**：太平静，第一眼惊艳度最低；「高级感」依赖字体质量（需引入一款优秀的中文字重家族，如 HarmonyOS Sans / MiSans 的 800 字重）。

## 三、三案共享的功能覆盖（对照上轮，无一遗漏）

队列、定时关闭（预设+自定义+播完停）、无限随机、关联播放、随心播放、四类目曲库+情绪标签、本地导入、歌单续播、批量播放四键、拖拽排序、多版本切换、Hi-Res 徽章、情绪分析（进度+继续）、随心时段、播放统计（目标环+周柱+TOP 榜）、文件校验、外观主题入口、迷你播放条、歌词（卡拉OK+字号）——全部在场，全部用本名。多版本 A/B、秒切、版本对比等二级页沿用各案语言，定稿后补第二批。

## 四、定稿后落地提示（未实施）

- 暖砂 / 留白：主要是令牌级改造（颜色、圆角、阴影、字号），可先做「骨架不变、令牌全换」的快速版。
- 流光：需要封面取色管线（Palette API 或自研）+ Compose 的 blur/绘图层支持，改造集中在背景层与控件层，建议作为独立骨架注册进现有 skin 体系。
