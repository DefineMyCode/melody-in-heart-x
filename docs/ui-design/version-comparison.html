版本对比，差异一眼可见Version Comparison

多版本管理从「能看出有几个版本」升级到「一眼看出差别在哪」。同名歌曲的多个版本以规格对比表呈现： 相同信息折叠收起、差异单元高亮、可选对比基准、音质条一眼辨高低，并支持文件路径对比。 针对 4 个版本左右的歌曲，首列固定 + 横滑 + 折叠共同项，手机上依然不拥挤。

共同折叠 · 差异高亮 基准切换 · 音质条对比 文件路径对比 · 真实路径核对 对比完删除 · 二次确认
01 / 折叠

共同项先收起来

歌名、艺术家、封面等所有版本一致的字段折叠进一张「各版本一致」卡片，表格里只留真正有差异的行——注意力不浪费在重复信息上。

对比表 · 仅差异行
02 / 基准

选一个基准再比对

默认以音质最高的版本为基准，点击版本卡可随时换基准；与基准相同的值灰化、不同的值以朱砂高亮，差异关系一目了然。

高亮 = 与基准不同
03 / 4 版

4 个版本也不挤

规格表首列固定、横向滑动；≤3 版本自动收窄无需滚动，4+ 版本横滑保底。音质条独立呈现，每个版本的规格高低一眼可读。

首列固定 · 横滑 · 音质条
04 / 删除

选完就清理，释放空间

确定保留的版本后，可直接删除其余本地文件。每个版本卡提供「⋯」入口，删除前弹窗明确展示将删除的文件与占用空间，强调不可撤销。

03

设计说明 · 差异如何被突出

四条规则保证「差异一眼可见」且「4 版本不拥挤」，落地时严格按规则计算。

N1 折叠相同，只留差异

对所有版本一致的属性（歌名、艺术家、专辑、封面等）自动折叠进「各版本一致」卡片，对比表只渲染至少存在一处差异的行。版本越多，折叠收益越大——4 个版本时通常只剩 6–8 行。

N2 基准比对，高亮不同

基准默认取推荐版本（音质评分最高者）。每行以基准值为参照：相同 → 灰化弱化；不同 → 朱砂描边浅底 + 加粗。点版本卡 / 表头 / 路径行任意位置换基准，全表即时重算高亮。

  • 推荐 = 采样率 × 无损加权评分最高；评分相同再优先比特率高者
  • 数值行（采样率 / 比特率 / 大小）配迷你音质条，大小即量级

N3 4 版本的三道保障

「首列固定 + 横向滑动」让 4–6 列也有保底；≤3 列自动收窄、零滚动；音质条独立于文字，规格高低一眼读。大屏（平板）直接全列并排。

版本数手机平板
2–3全列并排，无需滑动并排 + 操作条
4–6首列固定 + 横滑全列并排
7+横滑 + 可切「两两对比」横滑

N4 选中与操作一体化

「所选版本」贯穿全页：点版本卡、规格对比表头或文件路径行任意一处都能切换所选，三处同步高亮。选中态用主题色描边 + 浅底 + 「已选」徽标，四套主题下均清晰可辨。规格表新增比特率行（从元数据读取，与「查看歌曲详情」同源）。

  • 版本卡 / 表头 / 路径行点击均可切换所选，高亮同步
  • 比特率行：有数据才显示，缺失版本标「未知」
  • 删除入口收拢到封面右下角（版本卡 / 路径行双入口，均二次确认）
  • 底部「播放选中」上方为可拖拽进度条，松手即跳转播放进度

N5 删除本地文件 · 全链路容错

对比的终点是取舍：保留哪个版本，其余本地文件可以清掉释放空间。删除不是常规操作，因此链路刻意「重」，杜绝误删。

  • 入口克制：藏在版本卡「⋯」菜单内，不占主操作位
  • 目标明确：弹窗展示被删版本封面 / 格式 / 规格 / 占用空间
  • 措辞锋利：红色强调「删除本地文件 + 移除歌单引用 + 不可撤销」
  • 反馈闭环：删除后版本卡与对比列移除、计数 4→3、Toast 提示释放空间
  • 删除进行中（文件较大时）版本卡显示进度态，失败则回滚并 Toast 报错
